Zoom POS Multi-Tenant SaaS & POS System

Complete User Guide, Technical Documentation & Deployment Manual for CodeCanyon

🚀 Overview & Architecture

Zoom POS SaaS is an enterprise-grade Multi-Tenant Point of Sale and SaaS billing platform built on Laravel, Livewire 3, Alpine.js, Tailwind CSS, and MySQL.

Core Capabilities & Feature Highlights

  • Dual POS Workflows: Seamlessly toggle between Retail / Grocery Barcode POS and Restaurant Dine-In POS with dining floors, table layouts, and Kitchen Order Tickets (KOT/KDS).
  • Continuous Thermal Receipt Printing: Exact millimeter-calibrated DomPDF and browser print engine supporting standard 58mm and 80mm continuous thermal rolls without right-edge text clipping or multi-page voids.
  • Quotation & Document Management: Issue professional client proposals, convert quotations directly into sales/invoices, deduct stock automatically, and export branded PDF slips.
  • Accounts Receivable & Cash Registers: Manage credit sales, installment tracking, register open/close shifts, and financial audit ledgers.
  • Multi-Tenancy & Custom Domains: Flexible tenant routing supporting subdomains ({tenant}.domain.com), path prefixes (/tenant/*), and dedicated custom domains.
  • 100% Offline Asset Delivery: Zero third-party CDN dependencies; all charts, rich-text editors, icons, and QR code engines are bundled locally.

💻 Server Requirements

Ensure your server or hosting account satisfies the following requirements:

Requirement Recommended / Mandatory Status
PHP Version PHP 8.2, 8.3, or 8.4 Mandatory
PHP Memory Limit 256MB or higher (512MB for high-volume POS) Mandatory
Database MySQL 8.0+ / MariaDB 10.5+ Mandatory
Required PHP Extensions BCMath, Ctype, cURL, DOM, Fileinfo, JSON, Mbstring, OpenSSL, PCRE, PDO, PDO_MySQL, Tokenizer, XML Mandatory
Graphics Extension GD or Imagick (for QR Codes & Barcodes) Mandatory

⚡ 1-Click Interactive Web Installer

Zoom POS comes with a standalone graphical web installer at /install.

Installation Steps:

  1. Upload the script files to your web server root.
  2. Navigate to https://yourdomain.com/install in your web browser.
  3. Step 1: System checks verify PHP extensions, memory limit, and folder write permissions.
  4. Step 2: Enter your database credentials (Host, Port, Database Name, User, Password) and click Test Connection.
  5. Step 3: Click Run Database Migrations & Seed Defaults.
  6. Step 4: Create your primary Super Admin account and enter your CodeCanyon Purchase Code.
  7. Step 5: Click Complete & Lock Installation to generate the application encryption key and lock the installer.

🌐 cPanel / Plesk Hosting Setup

  1. Set Document Root: In cPanel > Domains, point your domain's Document Root to the /public directory of the project (e.g. public_html/public or subdomain/public).
  2. Create MySQL Database: In cPanel > MySQL Databases, create a database, user, and assign full permissions.
  3. Upload & Extract: Upload the source archive into your hosting folder and extract.
  4. Configure Permissions: Ensure storage/ and bootstrap/cache/ have write permissions (chmod -R 775 storage bootstrap/cache).
  5. Run Installer: Visit https://yourdomain.com/install to finalize.

🖥️ VPS / Nginx & Apache Configuration

Sample Nginx Server Block:

server {
    listen 80;
    server_name yourdomain.com *.yourdomain.com;
    root /var/www/zoom-pos/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

⏰ Cron Job & Task Scheduler

Laravel's task scheduler manages subscription renewals, overdue invoice reminders, inventory alerts, and database cleanups. Add the following cron job to your server:

* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1
💡
In cPanel, go to Cron Jobs > Select Once Per Minute (* * * * *) > Enter the command above replacing /path-to-your-project with your absolute server path.

💳 Payment Gateways Setup

Super Admins can enable payment gateways in the Super Admin Console (Settings > Payment Gateways) or via .env:

  • Stripe: Enter Publishable Key, Secret Key, and Webhook Secret.
  • PayPal: Enter Client ID, Secret Key, and set Mode to live or sandbox.
  • Razorpay: Enter Key ID and Key Secret.
  • Mercado Pago: Enter Public Key and Access Token.

🖨️ Thermal Receipt Printing Setup (58mm & 80mm)

Zoom POS features precision CSS print media rules and dynamic PDF millimeter canvas sizing tailored for standard POS thermal receipt printers (Epson, Star Micronics, Xprinter, MUNBYN, Rongta, etc.):

  • Continuous Roll Output: The layout automatically calculates item counts and sub-lines to fit receipts onto a single continuous roll without blank bottom voids.
  • Browser Direct Print: Click Print Receipt in POS to invoke native browser printing configured with @media print zero-margin safety padding.
  • Paper Size Setting: Store managers can toggle between 58mm (standard compact) and 80mm (wide format) in Store Settings > POS Configuration.

🛠️ Troubleshooting & Frequently Asked Questions

1. Storage permission error / 500 Internal Server Error:

Run the following commands in your server terminal:

chmod -R 775 storage bootstrap/cache
php artisan storage:link

2. How to reset Super Admin password:

Use Laravel Tinker:

php artisan tinker
App\Models\PlatformAdmin::first()->update(['password' => Hash::make('NewPassword123')]);

3. Clearing optimization caches after updates:

php artisan optimize:clear
php artisan config:cache
php artisan route:cache
php artisan view:cache
