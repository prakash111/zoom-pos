## 6. How to Submit on CodeCanyon

1. Log in to your **Envato Author Dashboard** &rarr; **Upload** &rarr; Select **CodeCanyon** &rarr; **PHP Scripts**.
2. Copy and paste the title from Section 1 above.
3. Open [`CODECANYON_DESCRIPTION.html`](file:///home/zoomnearby-saas/htdocs/saas.zoomnearby.com/public/documentation/CODECANYON_DESCRIPTION.html), copy the HTML code, and paste it directly into the **Item Description** editor.
4. Upload `codecanyon_thumbnail_80x80.jpg` as the **Thumbnail**.
5. Upload `codecanyon_preview_590x300.jpg` as the **Inline Preview Image**.
6. In **Main File (.zip)**, upload the full source package including:
   - Laravel Backend & Multi-Tenant core files
   - Flutter App source project (Android, Windows, Web)
   - Central License Manager script
   - Documentation folder
7. In **Tags**, paste the 30 tags from Section 2.
8. Enter demo credentials and URLs in the Reviewer Notes field.
9. Click **Submit for Review**.
